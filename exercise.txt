Ex. 4 React Lab Exercise: Event Handling in React 
  Aim 
To understand and implement event handling in React using events such as onClick, onChange, 
and onSubmit. 
 
1. What is Event Handling? 
Event handling means responding to an action performed by the user. 
Examples: 
• Clicking a button → onClick 
• Typing in a textbox → onChange 
• Submitting a form → onSubmit 
• Moving the mouse → onMouseOver 
Basic Flow 
User Action 
     ↓ 
React Event 
     ↓ 
Event Handler Function 
     ↓ 
State / UI Update

Step 3: Understanding onClick 
The important line is: 
<button onClick={handleClick}> 
It means: 
When the button is clicked, execute handleClick. 
❌ Incorrect 
<button onClick={handleClick()}> 
This calls the function during rendering. 
✅ Correct 
<button onClick={handleClick}> 
The function is called when the event occurs. 
 
Step 4: Event Handling with State 
Now let's display the number of button clicks. 

Import useState: 
import { useState } from "react"; 
 
function App() { 
 
  const [count, setCount] = useState(0); 
 
  function handleClick() { 
    setCount(count + 1); 
  } 
 
  return ( 
    <div> 
      <h1>Click Counter</h1> 
 
      <p>Button clicked: {count} times</p> 
 
      <button onClick={handleClick}> 
        Click Me 
      </button> 
    </div> 
  ); 
} 
 
export default App; 
Output 
Initially:

Button clicked: 0 times 
 
[ Click Me ] 
After one click: 
Button clicked: 1 times 
After three clicks: 
Button clicked: 3 times 
 
Step 5: onChange Event 
The onChange event is commonly used with input fields. 
import { useState } from "react"; 
 
function App() { 
 
  const [name, setName] = useState(""); 
 
  function handleChange(event) { 
    setName(event.target.value); 
  } 

 
  return ( 
    <div> 
      <h1>Student Name</h1> 
 
      <input 
        type="text" 
        value={name} 
        onChange={handleChange} 
        placeholder="Enter your name" 
      /> 
 
      <p>Hello, {name}</p> 
    </div> 
  ); 
} 
 
export default App;

        ↓ 
event.target.value 
        ↓ 
setName(...) 
        ↓ 
React updates UI

Step 6: Understanding the Event Object 
React provides an event object to the event handler. 
function handleChange(event) { 
  console.log(event); 
} 
For an input: 
event.target 
refers to the input element. 
And: 
event.target.value 

gives the value typed by the user. 
For example: 
Input: 
[ Ajith ] 
 
event.target.value 
        ↓ 
     "Ajith" 
 
Step 7: Handling Form Submission 
Create a simple student form: 
import { useState } from "react"; 
 
function App() { 
 
  const [name, setName] = useState(""); 
 
  function handleSubmit(event) { 
    event.preventDefault(); 
 
    alert("Student Name: " + name); 
  } 
 
  return ( 
    <div> 
      <h1>Student Registration</h1> 
 
      <form onSubmit={handleSubmit}> 
 
        <input 
          type="text" 
          placeholder="Enter student name" 
          value={name} 
          onChange={(event) => setName(event.target.value)} 
        /> 
 
        <button type="submit"> 
          Submit 
        </button> 
 
      </form> 
    </div> 
  ); 
} 
 
export default App; 
Important 
event.preventDefault(); 
prevents the browser's default form submission behavior, allowing React to handle the submission. 
 

Step 8: Multiple Events 
React can handle multiple events in the same component. 
import { useState } from "react"; 
 
function App() { 
 
  const [name, setName] = useState(""); 
 
  function handleClick() { 
    alert("Button clicked!"); 
  } 
 
  function handleChange(event) { 
    setName(event.target.value); 
  } 
 
  return ( 
    <div> 
 
      <h1>React Events</h1> 
 
      <button onClick={handleClick}> 
        Click Me 
      </button> 
 
      <br /><br /> 
 
      <input 
        type="text" 
        value={name} 
        onChange={handleChange} 
        placeholder="Enter name" 
      /> 
 
      <p>Name: {name}</p> 
 
    </div> 
  ); 
} 
 
export default App;
